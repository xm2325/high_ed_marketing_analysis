# CV project entry — V5.2

**University Recruitment Marketing Analytics Tool** | Python, Streamlit, Plotly, workflow automation, GitHub Actions

Built and deployed an interactive recruitment-marketing operations prototype using public University of Manchester evidence and clearly labelled synthetic workflow data. Added a time-sensitive campaign calendar, admissions-cycle reporting, international-market monitoring, CRM follow-up queues, digital-journey analytics, and a Marketing Action Centre that converts selected objectives into consent-aware triggers, timed communication playbooks, named owner teams, KPIs, measurement specifications, and downloadable CSV/ICS action plans.
